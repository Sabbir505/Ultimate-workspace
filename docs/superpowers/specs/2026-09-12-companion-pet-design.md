# Companion Pet — Design

**Date:** 2026-09-12 · **Branch:** `feat/companion-pet` · **Status:** approved in chat (user picked: pixel-art sprites; cat + axolotl + robot; pet lives above the sidebar search AND above the chat composer; walk/work behaviors; all phases; live-tested with assets double-checked)

## Concept

A small pixel-art pet that lives in Relay and reacts to what the app and its
agents actually do. It is presence, not a chore: no hunger, no death, no guilt
mechanics (explicit design rule after the Duolingo-owl research; Finch's
non-punishing loop is the model). The pet's moods mirror real app state, so it
doubles as an ambient status indicator.

## Product decisions (user-approved)

- **Species:** cat, axolotl, robot — selectable in the pet panel.
- **Art:** pixel-art sprite sheets, 32×32 frames, generated by a committed
  script (`scripts/generate_pet_sprites.mjs`, zero deps) into `public/pets/`.
  A generated contact sheet is used for visual QA of the assets.
- **Homes:** (1) a strip in `SidebarHeader` directly above the search button,
  (2) a strip directly above `.chat-composer-card` in the composer. Both render
  the same synchronized pet state (the same pet "gets around").
- **Behavior:** idle, walk (random strolls within the strip), watching (chat
  streaming), working (agent-pane PTY output), celebrating (turn/automation
  success), concerned (error/crash), dozing (idle ≥ 4 min), happy (petted).
- **Progression:** XP from real events (turn completed +6, automation ok +10,
  error survived +1); levels unlock cosmetic hats (party, headphones, wizard,
  crown) drawn as a shared overlay sprite anchored per species. No evolution
  stages — re-drawing every animation per stage tripled the art surface for
  little delight; hats carry the progression instead.
- **Voice (phase 3):** rare, throttled speech bubbles with curated per-species
  lines on mood transitions, plus a "while you were away" morning digest built
  from the notification center. No LLM-generated lines (cost/latency not worth
  a cosmetic; deterministic lines read better).

## Architecture

The core is a pure mood state machine; rendering and wiring are swappable
around it.

```
existing app state ──► usePetEvents (hook, App-level) ──► pet store ──► PetStrip ×2 ──► PetActor
(chat streaming map,     + PetTicker (single rAF)          (Zustand,      (sidebar,      (sprite,
 notifications center,                                     localStorage   composer)      flip, bubble,
 pane exits, PTY data)                                     persistence)                  Zzz, hearts)
```

- `src/state/pet.ts` — store + pure `reducePet(state, event)` and
  `tickPet(state, now)` (walk progress, mood cooldowns, idle→doze, random
  strolls, frame clocks). Fully unit-tested.
- `src/hooks/usePetEvents.ts` — bridges real app state into pet events:
  subscribes to the chat store's `streaming` map, the notifications store
  (`completed`/`automation ok` → celebrate; `error`/`crash` → concerned), pane
  `exited/crashed`, raw PTY data events (→ working), document visibility
  (pause), and mounts the idle ticker.
- `src/components/pet/PetActor.tsx` — renders one frame of the species sheet
  (`image-rendering: pixelated`, `scaleX(-1)` for left-facing), speech bubble,
  Zzz/hearts particles.
- `src/components/pet/PetStrip.tsx` — the strip container (sidebar/composer
  variant); click opens `PetPanel`.
- `src/components/pet/PetPanel.tsx` — popover: rename, species picker, level +
  XP bar, cosmetic toggles, per-home show/hide, "pet the pet" (happy + heart),
  activity digest.
- `src/components/pet/PetTicker.tsx` — one rAF loop driving `tickPet`; pauses
  on `visibilitychange` and when the pet is disabled.
- Generated assets: `public/pets/{cat,axolotl,robot,hats}.png` +
  `contact-sheet.png` (QA only) + `src/lib/pets/manifest.ts` (frame maps,
  fps, head anchors for hats).

## Guardrails (from research)

Opt-in-off-able in one click (panel + Settings); no OS notifications and no
sound from the pet, ever; animations pause when the window is hidden; honour
`prefers-reduced-motion` (poses still change, motion doesn't); mood
transitions are debounced so streaming chats don't flicker the sprite; never
punishing — neglect only makes the pet nap.

## Testing

- vitest: reducer transitions, cooldowns, doze, walk bounds, XP/level/unlock
  math, persistence round-trip.
- `tsc --noEmit` clean.
- Asset QA: generated contact sheet reviewed visually (transparency, frame
  alignment, palette consistency) before wiring.
- Live test in `npm run tauri dev`: pet visible in both homes, strolling,
  mood changes forced via a dev-only `window.__pet` debug hook (DEV builds
  only) plus real triggers (agent pane output → working; chat turn →
  celebrate; kill a pane → concerned), panel interactions, persistence across
  restart.

## Out of scope

Mobile companion rendering (protocol + RN UI — desktop first; state shape is
sync-ready), LLM-generated pet lines, sound.
