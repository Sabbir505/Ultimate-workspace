What exactly is Relay?

Relay is a local-first desktop workspace for AI coding agents. It combines supported agent CLIs, built-in chat, native browser panes, git tools, persistent memory, and scheduled automations.

Do I need to switch my coding agent?

No. Relay supports Claude Code, Kimi Code CLI, OpenCode, Pi, Omp, and CommandCode. You can also use built-in chat with your chosen model provider.

Can I use local models?

Yes. Browse, download, and run GGUF models from Hugging Face through llama-server. Performance depends on your hardware and the model you choose.

Does everything stay on my machine?

Your workspace is local. Cloud model providers and connected services still receive data when you use them. Local GGUF models offer an on-device inference option.

How do I get started?

Get the Windows installer from GitHub Releases, then connect a supported agent CLI or configure built-in chat. For development setup, see the quick start.
