BEFORE YOU GET STARTED

A few good
questions.

What exactly is Relay?

Relay is a local-first desktop workspace for AI coding agents. It hosts the agent CLIs you already use — Claude Code, Kimi Code, OpenCode, Pi, Omp, and CommandCode — alongside a built-in chat, plus a terminal, native browser, git tools, a markdown vault, persistent memory, and scheduled automations.

Do I need to switch my coding agent?

No. Bring the CLIs you already run, or use built-in chat with your own model provider. Sessions keep their history, and you can move a conversation between engines mid-thread.

Can I use local models?

Yes. Browse and download GGUF models from Hugging Face and run them on your machine with llama-server. Local image generation and on-device voice are built in too. Performance depends on your hardware and the model you choose.

Where does my data live?

Your workspace, chats, notes, and memory live on your machine, in a local database and folders you choose. The file tools stay inside the folders you grant. Cloud providers and connected services still receive whatever you send them.

Does Relay run on my operating system?

Relay ships for Windows today — grab the installer from GitHub Releases. The stack is cross-platform, but Windows is the supported target for now.

Is there a mobile app?

Yes. Grab the Android APK from GitHub Releases, then pair the companion app over a QR code or Tailscale to run chats, answer approvals, and get notifications from your phone. The connection is end-to-end encrypted and your API keys never leave the desktop.

How do I get started?

Get the Windows installer from GitHub Releases, then connect a supported agent CLI or configure built-in chat.
