# Conduit Architecture Refactor — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Refactor the Conduit codebase to a clean per-feature module structure, eliminate the audit-surfaced performance bottlenecks, and hit the measurable acceptance criteria in the design spec.

**Architecture:** 5 binding decisions (Channel<T> for streams, rAF-batched streaming render, rusqlite + WAL + spawn_blocking, Vite manualChunks + lazy, per-feature folder decomposition with re-exports) applied across 30 tasks in 6 phases + 2 dependencies.

**Tech Stack:** Tauri 2, React 18, TypeScript, Rust (rusqlite, tokio, portable-pty, zustand), Vite 5.

## Global Constraints

- **No behavior change** in any refactor task (split, move, rename) — pure mechanical decomposition. Behavior changes only happen in the perf-fix tasks (Phase 4 + 5) and they are scoped narrowly.
- **Backward-compat re-exports** at every split boundary so caller sites don't churn.
- **Tests move with their code** — every `#[cfg(test)] mod tests` block relocates to the new home.
- **No new dependencies** unless the task explicitly calls it out (only 5.3 lists new deps).
- **No new `unsafe` blocks.** No new `TODO`/`FIXME`/`HACK`/`XXX`.
- **One commit per task** with a conventional-commit message.
- **Live-verify after every task** that touches user-facing code: rebuild, smoke-test the affected feature, confirm visually.
- **Update `AI CONTEXT/BUILD_LOG.md` after every task** with what shipped, what was tested, any deviations.
- **Run autoreview after every phase**, not after every task (faster + still catches cross-task issues). Exception: Phase 4 perf fixes get autoreview per task (small surface, easy to break).
- **Restart the app after every code change** per `restart-app-on-change` memory.
- **Build before commit:** `cargo check && npx tsc --noEmit`. If either fails, fix before committing.

## File structure conventions

New modules created by this plan follow the codebase's existing per-feature pattern:
- `src-tauri/src/<feature>/mod.rs` (or `<feature>.rs` for single-file features)
- `src-tauri/src/<feature>/<submodule>.rs` for sub-decompositions
- `src-tauri/src/<feature>/commands.rs` if a Tauri command surface is co-located
- Frontend: `src/components/<feature>/<File>.tsx` for new components, `src/state/<slice>.ts` for state slices
- Tests live next to the code they test (`#[cfg(test)] mod tests` for Rust, `.test.ts` co-located for Vitest)

```rust
use rusqlite::{params_from_iter, Connection};
use std::collections::HashMap;

#[derive(Debug, Clone)]
pub struct Project {
    pub id: String,
    pub name: String,
    pub path: String,
}

pub fn bulk_load_projects(conn: &Connection, ids: &[String]) -> rusqlite::Result<HashMap<String, Project>> {
    if ids.is_empty() {
        return Ok(HashMap::new());
    }
    let placeholders = std::iter::repeat("?").take(ids.len()).collect::<Vec<_>>().join(",");
    let sql = format!("SELECT id, name, path FROM projects WHERE id IN ({})", placeholders);
    let mut stmt = conn.prepare(&sql)?;
    let params = params_from_iter(ids.iter());
    let rows = stmt.query_map(params, |r| {
        Ok(Project { id: r.get(0)?, name: r.get(1)?, path: r.get(2)? })
    })?;
    let mut map = HashMap::new();
    for row in rows {
        let p = row?;
        map.insert(p.id.clone(), p);
    }
    Ok(map)
}
```

Note: shape the `Project` struct to match whatever `db/projects.rs` already returns. If a richer struct exists, use that. If only `id` + `name` are needed for the call sites, return a tuple-like struct.

```rust
use std::time::{Duration, Instant};

pub struct CoalesceBuffer {
    window: Duration,
    max_bytes: usize,
    buf: Vec<u8>,
    first_at: Option<Instant>,
}

impl CoalesceBuffer {
    pub fn new(window_ms: u64, max_bytes: usize) -> Self {
        Self { window: Duration::from_millis(window_ms), max_bytes, buf: Vec::new(), first_at: None }
    }

    pub fn push(&mut self, data: &[u8]) {
        if self.buf.is_empty() {
            self.first_at = Some(Instant::now());
        }
        self.buf.extend_from_slice(data);
    }

    /// Returns Some(chunk) if the buffer should flush now (window expired or size cap hit).
    pub fn try_flush(&mut self) -> Option<Vec<u8>> {
        if self.buf.is_empty() { return None; }
        let should_flush = self.buf.len() >= self.max_bytes
            || self.first_at.map_or(false, |t| t.elapsed() >= self.window);
        if should_flush {
            let chunk = std::mem::take(&mut self.buf);
            self.first_at = None;
            Some(chunk)
        } else {
            None
        }
    }
}
```

- [ ] **Step 3: Implement the hook**

```ts
import { useEffect, useRef, useState, useTransition } from "react";

export interface UseStreamingTextOpts {
  initial: string;
  incoming$: { subscribe(cb: (chunk: string) => void): () => void };
}

export function useStreamingText({ initial, incoming$ }: UseStreamingTextOpts) {
  const [displayed, setDisplayed] = useState(initial);
  const [, startTransition] = useTransition();
  const buffer = useRef<string>("");
  const rafId = useRef<number | null>(null);
  const subscribed = useRef(false);

  useEffect(() => {
    if (subscribed.current) return;
    subscribed.current = true;
    const unsub = incoming$.subscribe((chunk) => {
      buffer.current += chunk;
      if (rafId.current === null) {
        rafId.current = requestAnimationFrame(() => {
          rafId.current = null;
          const flushed = buffer.current;
          buffer.current = "";
          startTransition(() => setDisplayed((prev) => prev + flushed));
        });
      }
    });
    return () => { subscribed.current = false; unsub(); };
  }, [incoming$]);

  return { displayed };
}
```

```rust
    let mut stmt = conn.prepare("SELECT id, project_id, title, ... FROM sessions ORDER BY last_active_at DESC")?;
    let sessions: Vec<(String, String, String, ...)> = stmt.query_map([], |r| Ok((r.get(0)?, r.get(1)?, ...)))?.collect::<Result<Vec<_>>>()?;
    // 2) Bulk-load the projects
```

## Execution notes

- **The "live-verify" step in every task assumes the user restarts the app** per `restart-app-on-change` memory. Each task: commit → user restarts → next task.
- **Autoreview cadence:** after every phase. The exception is Phase 4 (perf fixes) which gets autoreview per task — small surface, easy to break, cheap to verify.
- **Rollback strategy:** every task is a single commit. If a task breaks something, `git revert` is one command. Don't fold tasks.
- **The "X" in a step checklist** is the user-facing check the user should do, not something the implementer runs in CI.
- **Autoreview agent** is the `pr-review-toolkit:code-reviewer` agent from the available list. Scope: changed files since the last commit.
