# Changelog

## v0.4.1 (2026-08-10)

- **Local Models with Hugging Face market** — Browse and download open-source GGUF models directly in the app. Vision models auto-pull their projector files. Zero-config, fully offline.
- **Git Sidebar + Plan Detection** — Conversations are scanned for AI-proposed plans, shown in a structured panel with diffs and branch state. Sidebar collapsed by default, one-click to inspect.
- **Mobile Session Chat** — Cursor-style chat UI on your phone, synced to desktop projects in real time.
- **Automations Redesign** — Dynamic model dropdown, headless runner via Task Scheduler (fires even when Conduit is closed).
- **Unified Single-Mode Layout** — Nested project chats, no mode-switching tabs.
- **Security Hardening** — Filesystem tools scoped, `run_code` sandboxed, CSP tightened.
- **Auto-Updates Live** — CI pipeline builds, signs, and ships every release. One-click update banner on startup.

## v0.3.2

- Initial public release with auto-update support.
