RELEASES & CHANGELOG

Every release,
on the record.

Dates below are taken from the git tag timeline — the day each version was actually cut. Installed copies auto-update from the update feed; everyone else can grab any installer directly.

  1. v0.6.0 2026-09-21 Latest

    The knowledge release. Vault — a markdown knowledge base the model genuinely works in — plus local image generation (sd.cpp, no cloud), automation triggers beyond cron (webhook, watched file, git HEAD, Gmail), user hooks around every tool call, hybrid knowledge search, a live harness model catalog, auto-refreshed pricing with a cache-savings hero, and a ~20% token-overhead diet per turn.

    Download for Windows Release page
  2. v0.5.0 2026-09-17

    345 commits of relief from single-chat amnesia: six panes in one window, Session Mesh (agents see and message each other), persistent memory, self-improving artifacts, plan-first document design, in-process read-aloud, browser agent v2, a notification center, auto model routing, a first-run wizard, three new harnesses (Pi, Omp, CommandCode), and the Conduit→Relay rename completed under the hood.

    Download for Windows Release page
  3. v0.4.2 2026-08-31

    The glass-and-documents release — and the one where Conduit became Relay on every screen. Full-fidelity document pipeline (PDF via Paged.js, DOCX, PPTX with in-app viewers), parallel subagents with tools, a CDP browser layer, queued-message notches, split chat view, a git file viewer with inline diffs, mobile remote access with E2E encryption + QR pairing, the MCP server gallery, per-turn RAG, and the liquid-glass UI across the app.

    Download for Windows Release page
  4. v0.4.1 2026-08-11

    Unified single-mode interface with nested project chats, plan detection & preview, a model market redesign, an automations redesign, grouped settings navigation, and faster streaming (rAF-batched tokens, channel-routed PTY output).

    Download (Conduit) Release page
  5. v0.4.0 2026-08-03

    Chat from your phone — session-scoped mobile chat over the relay WebSocket — plus the Windows CI release pipeline that builds and ships every version since.

    Download (Conduit) Release page
  6. v0.3.2 2026-07-29

    TypeScript build fixes.

    Download (Conduit) Release page
  7. v0.3.1 2026-07-28

    Updater embedded pubkey corrected to match the signing keypair.

    Download (Conduit) Release page
  8. v0.3.0 2026-07-27

    Documentation alignment: AI_CONTEXT.md and CONTRACT.md match the implementation.

    Download (Conduit) Release page
  9. v0.2.0 2026-07-23

    The first public build: artifact system with 30-day retention, vector SVG diagrams, a styled docx/pptx/pdf toolkit, agentic browser tools, vision uploads, and the OpenRouter provider.

    Download (Conduit) Release page
  10. v0.1.x 2026-07-21 → 2026-07-23

    Pre-release development: the initial desktop shell — Tauri, multi-pane PTY, browser panes, chat, git sidebar, local models, automations, cost dashboard. No public build was cut.

Versions before 0.4.2 shipped under the original product name, Conduit — same app, earlier name. Installer checksums and the signed update feed live on each release page.
