Behavior

  • Bots joins the destinations — same header strip as Automations/Wiki/Vault, same full-center swap, back/forward aware. Keybinding ⌘B mirrors the others.
  • The rail is the roster: dot, emoji, name, one-line description — second row exactly as specced. Row states: active (accent tint), working (pulsing dot), disabled (dimmed — Ledger is pending approval).
  • The center is the real ChatView bound to the bot's session — streaming, tools, approvals, artifacts all work. The same thread opens from Chat History; there is one conversation per bot, ever.
  • Job notes land inside the thread: a scheduled run appends to the bot's chat, so its history is one continuous story.
  • The identity chip in the composer is a tag, not a picker — you're inside Atlas's thread, and the chip says so.

Behavior

  • Five tools, mirroring the automations family: list_bots (read), create_bot / update_bot / delete_bot / run_bot (write-classified → approval flow).
  • Agent-created bots land disabled — same safety rail as agent-created automations. The rail shows them dimmed with a gold "pending" dot.
  • run_bot triggers a turn in the bot's own thread (optional prompt overrides the standing job) — the result appears in the Bots view, not inline, so each bot keeps one history.
  • Overlapping runs are guarded — run_bot on a working bot reports back instead of double-firing.
  • Every mutation emits bots:changed, so the rail, modal, and mobile list refresh live.

Spec

  • Live 3D, rendered right here — three.js (r160, same CDN delivery as the page fonts) with studio lighting, so this is the real material and motion, not an artist's still.
  • Silhouettes are the identity: Atlas the orbiter (ring + dish), Scout the watcher (one big lens), Ledger the accountant (receipt body + bindings). Palettes derive from each bot's dot color.
  • Four states per bot, matching Relay's status language: idle (float + blink), working (ring ping / lens scan / paper feed), waiting (gold "?" bob), done (hop + sparkles + green eyes). Auto-cycles every 4 s — click a state to pin it; auto resumes after 12 s.
  • Production path on approval (Task 8b): the same rigs ship in the app — Tauri's webview is WebGL2-capable — driving avatars in the rail, chat, and push; emoji + dot stay as the fallback.
  • Everything here is tunable — silhouette, colors, timing, lighting. Say what to change and I'll re-render.
