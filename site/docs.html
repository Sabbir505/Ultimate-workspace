What Relay is

Relay is a local-first desktop workspace for AI coding agents, built for Windows. It wraps the agent CLIs you already run — Claude Code, Kimi Code, OpenCode, Pi, Omp, and CommandCode — next to a built-in chat that talks to cloud providers or models on your own machine. Around the chats: a native browser pane, a git sidebar, a markdown Vault, scheduled automations, a cost dashboard, and a phone companion — one window instead of ten.

Install & update

  1. Grab the Windows installer from GitHub Releases and run it. No admin rights, no account.
  2. Relay checks for updates on startup and every four hours. When one is available you get a banner with the changelog and a one-click install.
  3. Prefer to browse versions yourself? Every release lives on the Releases page.

Bring your agents

In Settings → Agent harnesses you can one-click install any supported CLI; if you already have one, Relay finds it on your PATH. Each agent runs in its own pane with real terminal emulation, keeps its own sessions, and can be resumed later. Or skip the CLIs: the built-in chat connects to Anthropic, OpenAI, OpenRouter, any OpenAI-compatible endpoint, or local GGUF models — your keys, your accounts, stored in your OS keychain.

Agents are not islands: up to six chats share one window as resizable panes, and the Session Mesh lets them see, consult, and message each other.

Workspace & permissions

Pick a working folder and Relay scopes its file tools to the roots you grant — the agent works where you point it, not everywhere. Permission modes (read-only, plan, auto-edit, full auto) are one switch away in the composer, and native dialogs gate the few surfaces that execute arbitrary commands. A git sidebar with status, diffs, branches, worktrees and an AI diff review keeps the changes visible.

Local models

The built-in Model Market browses and downloads GGUF models from Hugging Face and serves them with llama-server — chat, read-aloud (Kokoro TTS), speech-to-text (whisper), and even image generation (sd.cpp) can run entirely on your machine, with optional CUDA builds one click away in Settings.

Vault, automations & more

  • Vault — a bound folder of markdown notes the model can genuinely work in: operator search, atomic writes, vault-wide [[wikilink]] rewrites, recoverable deletes, a local graph, and an in-app PDF viewer.
  • Automations — cron schedules that fire even while Relay is closed, plus event triggers: an inbound webhook, a watched file, a git HEAD change, or new Gmail activity.
  • Making things — designed DOCX/PPTX/PDF documents, mermaid diagrams, and local image generation surface as artifacts you can preview, export, and voice-read.
  • Memory — a persistent, inspectable memory survives across chats; a Settings browser shows every stored fact and its evidence.

Mobile companion

Relay Mobile (Android/iOS, built with Expo) pairs with the desktop over a QR code or Tailscale. Chats, approvals, notifications and automations follow you — end-to-end encrypted, and your API keys never leave the desktop.

Where your data lives

Workspace, chats, notes, memory, and artifacts live on your machine in a local database and folders you choose. Local-first doesn't mean offline-only: cloud providers and connected services receive whatever you send them — nothing more. There is no telemetry and no Relay-side account.
