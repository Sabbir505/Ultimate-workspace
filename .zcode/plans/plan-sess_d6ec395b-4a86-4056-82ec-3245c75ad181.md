# Conduit Conversational Artifact Creation — Final Implementation Plan

## Core Architecture

```text
                          CHAT
                            │
               ┌────────────┴────────────┐
               │                         │
       /create                    Natural Language
   deterministic              cheap detection
               │                         │
               └────────────┬────────────┘
                            ↓
                   Intent Classifier
                            ↓
                      Artifact Intent
                            ↓
                     Context Builder
                            ↓
               ┌────────────┼────────────┐
               │            │            │
         Conversation   Workspace   Existing Artifacts
               │            │            │
               └────────────┼────────────┘
                            ↓
                   Artifact Generator
              LLM + Structured Output
                            ↓
                      ArtifactSpec
                            ↓
                        Validator
                            ↓
                    ArtifactProposal
                            ↓
                   Proposal Card
                     │       │
               Regenerate  Edit
                     │       │
                     └───┬───┘
                         ↓
              Existing Editor
                         ↓
              User Confirmation
                         ↓
            Existing Tauri Command
                         ↓
            Existing Persistence
```

**Hard Rule**: Conversational layer produces **validated artifact specifications only**. Never implements persistence, execution, scheduling, or management.

---

## Phase 1: Minimal End-to-End Loop (ONLY THIS)

```
/create skill | loop | prompt | automation [instruction]
Natural language artifact detection (cheap filter → optional classifier)
Artifact Proposal Card (with Regenerate + Edit)
Preview → Existing Editor → Create
```

**Explicitly NOT in Phase 1:**
- Save As (conversation/message/selected)
- Message selection / selection mode
- Existing artifact retrieval before generation
- Semantic context builder (use simple recent messages)
- Missing fields / assumptions UI
- Update existing artifacts / diff
- Composition

---

## Phase 2 (After Phase 1 Works)
- Save As (conversation header, message actions)
- Message selection ("Select messages" from conversation menu)
- Existing artifact retrieval (search by name/description)
- Missing fields handling
- Assumptions display

## Phase 3
- Update existing artifacts through chat
- Diff preview
- Conversational artifact modification

### Intent Classifier (With Cheap Pre-Filter)

```rust
// intent.rs
#[derive(Serialize, Deserialize, Clone, Debug)]
pub struct ArtifactIntent {
    pub action: ArtifactAction,      // Create | None (Update/Save = Phase 2/3)
    pub artifact_type: Option<ArtifactType>,
    pub instruction: Option<String>,
}

#[derive(Serialize, Deserialize, Clone, Debug)]
#[serde(rename_all = "snake_case")]
pub enum ArtifactAction { Create, None }  // Update=Phase3, Save=Phase2

// Decision returned to frontend (no numerical thresholds exposed)
#[derive(Serialize, Deserialize, Clone, Debug)]
#[serde(tag = "decision")]
pub enum IntentDecision {
    CreateProposal { intent: ArtifactIntent },
    AskClarification { message: String },
    NormalConversation,
}

pub async fn classify_intent(
    user_message: &str,
    chat_session_id: &str,
) -> Result<IntentDecision, String> {
    // 1. Deterministic /create bypass
    if let Some(detected) = detect_create_command(user_message) {
        return Ok(IntentDecision::CreateProposal { intent: detected });
    }
    
    // 2. Cheap deterministic detection for obvious phrases
    if let Some(detected) = detect_obvious_intent(user_message) {
        return Ok(IntentDecision::CreateProposal { intent: detected });
    }
    
    // 3. LLM classifier for ambiguous cases
    let intent = llm_classify(user_message).await?;
    let decision = match intent.confidence {
        c if c >= 0.90 => IntentDecision::CreateProposal { intent },
        c if c >= 0.70 => IntentDecision::AskClarification { 
            message: format!("Do you want me to turn this into a {}?", intent.artifact_type.unwrap()) 
        },
        _ => IntentDecision::NormalConversation,
    };
    Ok(decision)
}
```

**Cheap deterministic patterns (no LLM call):**
```rust
fn detect_obvious_intent(msg: &str) -> Option<ArtifactIntent> {
    let lower = msg.to_lowercase();
    if lower.contains("turn this into a skill") || lower.contains("save this as a skill") {
        return Some(ArtifactIntent { action: ArtifactAction::Create, artifact_type: Some(ArtifactType::Skill), instruction: Some(msg.to_string()) });
    }
    if lower.contains("turn this into a loop") || lower.contains("make this run until") {
        return Some(ArtifactIntent { action: ArtifactAction::Create, artifact_type: Some(ArtifactType::Loop), instruction: Some(msg.to_string()) });
    }
    if lower.contains("save this as a prompt") || lower.contains("turn this into a prompt template") {
        return Some(ArtifactIntent { action: ArtifactAction::Create, artifact_type: Some(ArtifactType::PromptTemplate), instruction: Some(msg.to_string()) });
    }
    if lower.contains("make this run every") || lower.contains("create an automation") || lower.contains("schedule this") {
        return Some(ArtifactIntent { action: ArtifactAction::Create, artifact_type: Some(ArtifactType::Automation), instruction: Some(msg.to_string()) });
    }
    None
}
```

pub fn validate_artifact(proposal: &ArtifactProposal) -> ValidationResult {
    match &proposal.spec {
        ArtifactSpec::Skill(s) => validate_skill(s),
        ArtifactSpec::Loop(l) => validate_loop(l),
        ArtifactSpec::PromptTemplate(p) => validate_prompt_template(p),
        ArtifactSpec::Automation(a) => validate_automation(a),

    pub warnings: Vec<String>,
}
